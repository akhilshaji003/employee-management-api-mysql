# Submission checklist

- [ ] Extract project and inspect every source file
- [ ] Configure local MySQL credentials using environment variables
- [ ] Run `mvn clean test`
- [ ] Run `mvn spring-boot:run`
- [ ] Check Swagger UI at `/swagger-ui.html`
- [ ] Import the Postman collection and try CRUD + validation cases
- [ ] Create your own GitHub repository and push the project
- [ ] Add the GitHub repository URL to your submission email
- [ ] Be ready to explain the implementation in a code review

This ZIP contains the project, setup instructions, MySQL database configuration, API documentation through Swagger/OpenAPI, a Postman collection, sample request/response payloads and an automated test. It does not contain a GitHub repository URL because that must be created by you.
